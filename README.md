# 에듀프린트 AI 연결 도우미 — 내려받기 전용

이 저장소는 [에듀프린트](https://sjpt.kr/eduprint/) **AI 연결(내 구독으로 만들기)** 도우미의 실행 파일만 내려받게 두는 곳입니다.
직접 받을 필요는 없습니다. 에듀프린트 마이페이지 → **AI 연결** 에서 나오는 한 줄 설치 명령이 알아서 받고,
설치 스크립트에 적힌 지문(SHA-256)과 같은 파일만 설치합니다.

- 맥: Apple Silicon(`aarch64-apple-darwin`), Intel(`x86_64-apple-darwin`)
- 윈도우: x64(`x86_64-pc-windows-msvc.exe`)

도우미는 내 PC 의 Claude Code·Codex 를 도구를 모두 끈 채(파일 읽기·명령 실행 없음) 빈 임시 폴더에서 불러 글만 쓰고,
결과를 에듀프린트로 돌려보냅니다. 지우기: 마이페이지 → AI 연결 → 도우미 안내의 지우기 명령.

문의: 에듀프린트 고객지원.
